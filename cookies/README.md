# Cookies

ساده‌ترین روش: در ربات `/admin` ← **🍪 کوکی‌ها** را بزنید و فایل کوکی را همانجا بفرستید.
ربات فایل‌ها را خودش در این پوشه ذخیره می‌کند.

روش دستی: فایل‌های کوکی (فرمت Netscape) را با این نام‌ها اینجا بگذارید:

| فایل | کاربرد |
|------|--------|
| `instagram.txt` | تقریبا برای همه پست‌ها/ریلزها از روی سرور لازم است + استوری‌ها |
| `youtube.txt` | وقتی یوتیوب خطای «Sign in to confirm you're not a bot» می‌دهد |
| `pinterest.txt` | اختیاری |
| `soundcloud.txt` | اختیاری |

⚠️ این فایل‌ها محرمانه‌اند و در git ذخیره نمی‌شوند.
