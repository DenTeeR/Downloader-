# Cookies

فایل‌های کوکی (فرمت Netscape) را با این نام‌ها اینجا قرار دهید:

| فایل | کاربرد |
|------|--------|
| `instagram.txt` | تقریبا برای همه پست‌ها/ریلزها از روی سرور لازم است + استوری‌ها |
| `youtube.txt` | وقتی یوتیوب خطای «Sign in to confirm you're not a bot» می‌دهد |
| `pinterest.txt` | اختیاری |
| `soundcloud.txt` | اختیاری (برای کیفیت بالاتر با حساب Go+) |

راهنمای تهیه کوکی در فایل README اصلی پروژه آمده است.
⚠️ این فایل‌ها محرمانه‌اند و در git ذخیره نمی‌شوند.
