# 📥 ربات دانلودر تلگرام

ربات تلگرامی که لینک را از کاربر می‌گیرد، محتوا را دانلود می‌کند و فایل را در تلگرام برایش می‌فرستد.

| پلتفرم | چه چیزی دانلود می‌شود |
|--------|-----------------------|
| **اینستاگرام** | پست (عکس/ویدیو)، ریلز، کاروسل (چند عکس/ویدیو در یک آلبوم)، استوری |
| **یوتیوب** | ویدیو و شورتس با **منوی انتخاب کیفیت** (۲۴۰p تا ۴K با نمایش حجم)، فقط صدا (MP3)، کاور ویدیو |
| **پینترست** | پین عکس و ویدیو، لینک‌های کوتاه `pin.it`، بورد (تا سقف تعیین‌شده) |
| **اسپاتیفای** | آهنگ، آلبوم و پلی‌لیست به صورت MP3 با نام آهنگ، خواننده و کاور |
| **ساندکلود** | آهنگ و پلی‌لیست (MP3 با کاور) |

## ✨ امکانات

- 🇮🇷 رابط کاربری کاملا فارسی
- 📊 نمایش پیشرفت دانلود (درصد، حجم، سرعت)
- ⚡️ **کش هوشمند**: اگر لینکی قبلا دانلود شده باشد، بدون دانلود مجدد فورا ارسال می‌شود
- 🔒 **عضویت اجباری** در یک یا چند کانال (اختیاری)
- 👨‍💻 **پنل ادمین**: آمار کاربران و دانلودها (به تفکیک پلتفرم)، ارسال همگانی، مسدود کردن کاربر
- 🚦 صف دانلود و محدودیت دانلود هم‌زمان، هر کاربر فقط یک دانلود در لحظه
- 📦 پشتیبانی از فایل‌های تا **۲ گیگابایت** با سرور محلی Bot API
- 🌐 پشتیبانی از پروکسی (HTTP / SOCKS5)
- 🐳 اجرای ساده با Docker

## 🚀 راه‌اندازی

### ۱. ساخت ربات
در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید، دستور `/newbot` را بزنید و **توکن** را بگیرید.
آیدی عددی خودتان را هم از [@userinfobot](https://t.me/userinfobot) بگیرید (برای دسترسی ادمین).

### ۲. تنظیمات
```bash
git clone https://github.com/DenTeeR/Downloader-.git
cd Downloader-
cp .env.example .env
nano .env        # BOT_TOKEN و ADMIN_IDS را وارد کنید
```

### ۳-الف. اجرا با Docker (پیشنهادی)
```bash
docker compose up -d --build
docker compose logs -f bot      # مشاهده لاگ
```

### ۳-ب. اجرا بدون Docker
پیش‌نیازها: **Python 3.11+**، **ffmpeg** و **[Deno](https://deno.com)** (برای یوتیوب لازم است؛ به جای آن می‌توانید Node.js نصب کنید و `JS_RUNTIME=node` بگذارید).

```bash
# Ubuntu / Debian
sudo apt install -y python3 python3-venv ffmpeg
curl -fsSL https://deno.land/install.sh | sh

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

> 💡 سرور باید خارج از ایران باشد (یا `PROXY` را تنظیم کنید)، چون هم تلگرام و هم سایت‌های مبدا باید در دسترس باشند.

## ⚙️ متغیرهای `.env`

| متغیر | توضیح | پیش‌فرض |
|-------|-------|---------|
| `BOT_TOKEN` | توکن ربات (ضروری) | — |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، با کاما | — |
| `FORCE_JOIN_CHANNELS` | کانال‌های عضویت اجباری: `@ch1,@ch2` یا برای کانال خصوصی `-100123\|https://t.me/+link` | خاموش |
| `BOT_API_SERVER` | آدرس سرور محلی Bot API برای فایل‌های بزرگ | — |
| `MAX_FILE_SIZE_MB` | سقف حجم فایل | ۵۰ (با سرور محلی ۲۰۰۰) |
| `MAX_CONCURRENT_DOWNLOADS` | تعداد دانلود هم‌زمان | ۳ |
| `MAX_PLAYLIST_ITEMS` | سقف آهنگ‌های آلبوم/پلی‌لیست | ۱۰ |
| `CACHE_ENABLED` | ارسال فوری لینک‌های تکراری | `true` |
| `PROXY` | پروکسی، مثلا `socks5://127.0.0.1:1080` | — |
| `JS_RUNTIME` | `deno` یا `node` (برای یوتیوب) | `deno` |
| `YOUTUBE_POT_URL` | سرویس PO Token یوتیوب (پایین‌تر توضیح داده شده) | — |

## 🍪 کوکی‌ها (مهم برای اینستاگرام و یوتیوب)

اینستاگرام و یوتیوب درخواست‌هایی را که از IP سرورها (دیتاسنتر) می‌آیند محدود می‌کنند. اگر خطای
«نیاز به کوکی» یا «Sign in to confirm you're not a bot» دیدید، کوکی یک حساب را به ربات بدهید:

1. در مرورگر کروم/فایرفاکس افزونه **Get cookies.txt LOCALLY** را نصب کنید.
2. وارد سایت (مثلا instagram.com) شوید. **بهتر است از یک حساب فرعی استفاده کنید، نه حساب اصلی.**
3. با افزونه، کوکی‌ها را با فرمت Netscape خروجی بگیرید.
4. فایل را با نام `instagram.txt` (یا `youtube.txt`) در پوشه `cookies/` بگذارید. نیازی به ری‌استارت نیست.

## 📦 ارسال فایل‌های بزرگ‌تر از ۵۰ مگابایت

API عمومی تلگرام فقط تا ۵۰ مگابایت آپلود قبول می‌کند. با **سرور محلی Bot API** این سقف ۲۰۰۰ مگابایت می‌شود:

1. از [my.telegram.org](https://my.telegram.org) مقدار `api_id` و `api_hash` بگیرید و در `.env` به عنوان `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` بگذارید.
2. ربات را یک بار از سرور اصلی خارج کنید (یک بار در مرورگر باز کنید):
   `https://api.telegram.org/bot<TOKEN>/logOut`
3. در `.env` بنویسید: `BOT_API_SERVER=http://telegram-bot-api:8081`
4. اجرا: `docker compose --profile local-api up -d --build`

## ▶️ بهبود دانلود از یوتیوب (اختیاری)

اگر یوتیوب با وجود کوکی هم خطا داد، سرویس PO Token را فعال کنید:
```bash
# در .env:  YOUTUBE_POT_URL=http://pot-provider:4416
docker compose --profile youtube-pot up -d --build
```
(هر دو پروفایل را می‌توانید با هم فعال کنید: `--profile local-api --profile youtube-pot`)

## 🎵 نکته درباره اسپاتیفای

فایل‌های اسپاتیفای رمزگذاری شده (DRM) هستند و هیچ رباتی مستقیما از اسپاتیفای دانلود نمی‌کند.
این ربات (مثل بقیه ربات‌های مشابه) نام آهنگ، خواننده و کاور را از اسپاتیفای می‌خواند، همان آهنگ را در
**یوتیوب** (و اگر نشد در **ساندکلود**) پیدا می‌کند، آن را با کیفیت 192kbps به MP3 تبدیل می‌کند و
اطلاعات و کاور اسپاتیفای را روی فایل می‌نویسد. برای این کار به API key اسپاتیفای نیازی نیست.

## 👨‍💻 دستورات

| دستور | توضیح |
|-------|-------|
| `/start` | شروع و معرفی ربات |
| `/help` | راهنما |
| `/admin` | پنل مدیریت: آمار و ارسال همگانی (فقط ادمین) |
| `/ban 123456` | مسدود کردن کاربر (فقط ادمین) |
| `/unban 123456` | آزاد کردن کاربر (فقط ادمین) |
| `/cancel` | لغو ارسال همگانی |

**عضویت اجباری:** ربات را در کانال **ادمین** کنید، سپس آیدی کانال را در `FORCE_JOIN_CHANNELS` بگذارید.

## 🔧 نگهداری

سایت‌ها مدام تغییر می‌کنند؛ اگر دانلود از یک سایت از کار افتاد، اول ابزارهای دانلود را به‌روز کنید:
```bash
# Docker
docker compose build --no-cache bot && docker compose up -d
# بدون Docker
pip install -U yt-dlp gallery-dl
```

## 🗂 ساختار پروژه

```
bot/
├── __main__.py          # نقطه شروع (python -m bot)
├── config.py            # خواندن تنظیمات از .env
├── database.py          # SQLite: کاربران، آمار، کش file_id
├── platforms.py         # تشخیص پلتفرم، باز کردن لینک‌های کوتاه
├── middlewares.py       # ثبت کاربر، مسدودی، عضویت اجباری
├── handlers/            # start، admin، download (منوی کیفیت یوتیوب و ...)
├── services/
│   ├── downloader.py    # انتخاب ابزار مناسب برای هر لینک
│   ├── ytdlp.py         # یوتیوب، ساندکلود، ویدیوهای پینترست/اینستاگرام
│   ├── gallery.py       # عکس‌ها و کاروسل‌ها (gallery-dl)
│   ├── spotify.py       # خواندن اطلاعات آهنگ از اسپاتیفای
│   └── media.py         # ffmpeg: تامبنیل، ابعاد ویدیو، تگ MP3
├── sender.py            # ارسال فایل‌ها / آلبوم‌ها به تلگرام
├── progress.py          # پیام وضعیت و نوار پیشرفت
├── keyboards.py
└── texts.py             # همه متن‌های فارسی ربات
```

اجرای تست‌ها: `pip install -r requirements-dev.txt && BOT_TOKEN=x pytest`
