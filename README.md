# 📥 ربات دانلودر تلگرام

ربات تلگرامی که لینک را از کاربر می‌گیرد، محتوا را دانلود می‌کند و فایل را در تلگرام برایش می‌فرستد.
همه متن‌ها، استیکرها و دکمه‌های ربات از **داخل خود تلگرام** قابل طراحی است.

| پلتفرم | چه چیزی دانلود می‌شود |
|--------|-----------------------|
| **اینستاگرام** | پست (عکس/ویدیو)، ریلز، کاروسل (چند عکس/ویدیو در یک آلبوم)، استوری |
| **یوتیوب** | ویدیو و شورتس با **منوی انتخاب کیفیت** (۲۴۰p تا ۴K با نمایش حجم)، فقط صدا (MP3)، کاور ویدیو |
| **پینترست** | پین عکس و ویدیو، لینک‌های کوتاه `pin.it`، بورد |
| **اسپاتیفای** | آهنگ، آلبوم و پلی‌لیست به صورت MP3 با نام آهنگ، خواننده و کاور |
| **ساندکلود** | آهنگ و پلی‌لیست (MP3 با کاور) |

## ⚡️ نصب سریع (یک دستور)

روی یک سرور **Ubuntu یا Debian** (خارج از ایران) با کاربر root اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DenTeeR/Downloader-/main/install.sh)
```

اسکریپت از شما **توکن ربات** (از [@BotFather](https://t.me/BotFather)) و **آیدی عددی ادمین** (از [@userinfobot](https://t.me/userinfobot)) را می‌پرسد،
همه چیز را نصب می‌کند و ربات را به صورت سرویس همیشه‌روشن اجرا می‌کند. دو روش اجرا دارد:
**Docker** (پیشنهادی، با امکان فایل‌های تا ۲ گیگ) یا **Python + systemd** (سبک‌تر).

بعد از نصب، دستور `dlbot` در دسترس است:

| دستور | کار |
|-------|-----|
| `dlbot logs` | مشاهده لاگ زنده |
| `dlbot restart` | ری‌استارت |
| `dlbot update` | به‌روزرسانی ربات و ابزارهای دانلود (yt-dlp, gallery-dl) |
| `dlbot config` | ویرایش تنظیمات (.env) |
| `dlbot status` / `start` / `stop` | وضعیت / روشن / خاموش |
| `dlbot uninstall` | حذف کامل |

## ✨ امکانات

- 🇮🇷 رابط کاربری کاملا فارسی
- 🎨 **استودیو طراحی داخل ربات**: متن، استیکر، ایموجی پرمیوم، رنگ و جای دکمه‌ها (پایین‌تر توضیح داده شده)
- 📊 نمایش پیشرفت دانلود (درصد، حجم، سرعت)
- ⚡️ **کش هوشمند**: لینکی که قبلا دانلود شده بدون دانلود مجدد فورا ارسال می‌شود
- 🔒 **عضویت اجباری** در یک یا چند کانال
- 👨‍💻 **پنل ادمین**: آمار کاربران و دانلودها، ارسال همگانی، مسدود کردن کاربر
- 🍪 **مدیریت کوکی از داخل ربات** + هشدار خودکار به ادمین وقتی کوکی منقضی شود
- 🚦 صف دانلود، هر کاربر یک دانلود در لحظه
- 📦 فایل‌های تا **۲ گیگابایت** با سرور محلی Bot API
- 🌐 پشتیبانی از پروکسی (HTTP / SOCKS5)

## 🎨 طراحی ربات (متن، استیکر، ایموجی پرمیوم، دکمه‌های رنگی)

در ربات `/admin` ← **🎨 طراحی ربات** را بزنید. هیچ کدنویسی لازم نیست:

**📝 متن‌ها و استیکرها** — همه صفحه‌های ربات (شروع، راهنما، در حال دانلود، خطاها، منوی یوتیوب، کپشن فایل‌ها و ...)
- **ویرایش متن**: متن جدید را مثل یک پیام عادی در تلگرام بنویسید و بفرستید. **بولد، ایتالیک، لینک، اسپویلر، نقل‌قول و ایموجی پرمیوم** دقیقا همان‌طور ذخیره می‌شوند.
- متغیرهایی مثل `{name}` (نام کاربر) یا `{size}` (حجم) در هر صفحه نشان داده می‌شوند.
- **استیکر**: برای هر صفحه یک استیکر (معمولی، متحرک یا ویدیویی) بگذارید؛ مثلا یک استیکر لودینگ برای «در حال دانلود» که بعد از اتمام خودکار پاک می‌شود.
- **پیش‌نمایش کامل**: صفحه را دقیقا همان‌طور که کاربر می‌بیند ببینید.

**🔘 دکمه‌ها، رنگ و چیدمان** — پیش‌نمایش زنده کیبورد را می‌بینید؛ روی هر دکمه بزنید تا تنظیماتش باز شود:
- ✏️ **متن دکمه**
- 🎨 **رنگ**: 🔵 آبی، 🟢 سبز، 🔴 قرمز یا پیش‌فرض
- 💎 **ایموجی پرمیوم** کنار متن دکمه
- ⬆️⬇️ **جابجایی** بین ردیف‌ها، ◀️▶️ جابجایی در ردیف
- ⬜️ **اندازه**: دکمه تنها در یک ردیف = تمام‌عرض؛ «کنار دکمه‌های بالا» = نصف/یک‌سوم عرض
- 🙈 **مخفی/نمایش** هر دکمه
- ➕ **دکمه لینک** دلخواه (مثلا کانال شما) در هر کیبورد، حتی **زیر فایل‌های ارسالی**
- 📐 **چیدمان متنی** برای حرفه‌ای‌ها: هر خط یک ردیف، مثلا:
  ```
  q1080 q720 q480
  q360 q240
  audio cancel
  ```

**📄 صفحه‌های سفارشی** — صفحه‌های جدید مثل «درباره ما»، «پشتیبانی» یا «تعرفه‌ها» با متن و دکمه‌های خودشان بسازید و با «➕ دکمه صفحه» به آن‌ها لینک بدهید.

**📤 خروجی / 📥 ورود** — کل طراحی را به صورت فایل `design.json` بک‌آپ بگیرید یا به ربات دیگری منتقل کنید.

> 💎 **ایموجی پرمیوم** (در متن و کنار دکمه‌ها) فقط وقتی نمایش داده می‌شود که **صاحب ربات (اکانتی که ربات را در BotFather ساخته) تلگرام پرمیوم** داشته باشد.
> اگر نداشته باشد، ربات خودکار به جای آن‌ها ایموجی معمولی می‌گذارد و هیچ پیامی خراب نمی‌شود. **رنگ دکمه‌ها به پرمیوم نیاز ندارد.**

## 🍪 اینستاگرام و یوتیوب (کوکی)

اینستاگرام (و گاهی یوتیوب) اجازه دانلود از IP سرورها را نمی‌دهند، مگر ربات با یک حساب وارد شده باشد.
این کار از **داخل ربات** انجام می‌شود و نیازی به دسترسی به سرور نیست:

1. `/admin` ← **🍪 کوکی‌ها** ← **❓ آموزش تهیه کوکی** (آموزش قدم‌به‌قدم برای کامپیوتر و گوشی)
2. با یک **حساب فرعی** وارد instagram.com شوید و با افزونه **Get cookies.txt LOCALLY** (کامپیوتر) یا **Cookie-Editor** (فایرفاکس اندروید) خروجی بگیرید.
3. **📤 ارسال کوکی اینستاگرام** را بزنید و فایل (یا متن کپی‌شده) را بفرستید. تمام!

ربات فرمت را خودش تشخیص می‌دهد (txt، JSON یا متن)، فقط کوکی‌های همان سایت را نگه می‌دارد و پیام حاوی کوکی را از چت پاک می‌کند.
اگر کوکی منقضی شود، **ربات خودش به ادمین‌ها هشدار می‌دهد** و دکمه ارسال کوکی جدید را می‌فرستد.

## 🎵 نکته درباره اسپاتیفای

فایل‌های اسپاتیفای رمزگذاری شده (DRM) هستند و هیچ رباتی مستقیما از اسپاتیفای دانلود نمی‌کند.
این ربات نام آهنگ، خواننده و کاور را از اسپاتیفای می‌خواند، همان آهنگ را در **یوتیوب** (و اگر نشد در **ساندکلود**)
پیدا می‌کند و MP3 را با اطلاعات و کاور اسپاتیفای تحویل می‌دهد. نیازی به API key اسپاتیفای نیست.

## ⚙️ تنظیمات `.env`

| متغیر | توضیح | پیش‌فرض |
|-------|-------|---------|
| `BOT_TOKEN` | توکن ربات (ضروری) | — |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، با کاما | — |
| `FORCE_JOIN_CHANNELS` | کانال‌های عضویت اجباری: `@ch1,@ch2` یا برای کانال خصوصی `-100123\|https://t.me/+link` (ربات باید ادمین کانال باشد) | خاموش |
| `BOT_API_SERVER` | سرور محلی Bot API برای فایل‌های بزرگ | — |
| `MAX_FILE_SIZE_MB` | سقف حجم فایل | ۵۰ (با سرور محلی ۲۰۰۰) |
| `MAX_CONCURRENT_DOWNLOADS` | تعداد دانلود هم‌زمان | ۳ |
| `MAX_PLAYLIST_ITEMS` | سقف آهنگ‌های آلبوم/پلی‌لیست | ۱۰ |
| `CACHE_ENABLED` | ارسال فوری لینک‌های تکراری | `true` |
| `PROXY` | پروکسی، مثلا `socks5://127.0.0.1:1080` | — |
| `JS_RUNTIME` | `deno` یا `node` (برای یوتیوب) | `deno` |

## 🛠 نصب دستی (بدون اسکریپت)

```bash
git clone https://github.com/DenTeeR/Downloader-.git && cd Downloader-
cp .env.example .env && nano .env        # BOT_TOKEN و ADMIN_IDS
docker compose up -d --build             # با Docker
# یا بدون Docker (نیاز به Python 3.11+، ffmpeg و Deno):
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python -m bot
```

**فایل‌های بزرگ‌تر از ۵۰ مگ:** `api_id` و `api_hash` را از [my.telegram.org](https://my.telegram.org) بگیرید و در `.env` بگذارید،
`BOT_API_SERVER=http://telegram-bot-api:8081` را تنظیم کنید و با `docker compose --profile local-api up -d --build` اجرا کنید
(نصب‌کننده این کارها را خودش انجام می‌دهد).

## 🗂 ساختار پروژه

```
bot/
├── __main__.py          # نقطه شروع (python -m bot)
├── config.py            # خواندن تنظیمات از .env
├── database.py          # SQLite: کاربران، آمار، کش، طراحی
├── platforms.py         # تشخیص پلتفرم، باز کردن لینک‌های کوتاه
├── middlewares.py       # ثبت کاربر، مسدودی، عضویت اجباری
├── alerts.py            # هشدار کوکی به ادمین‌ها
├── ui/                  # 🎨 موتور طراحی
│   ├── texts.py         #   متن پیش‌فرض همه صفحه‌ها
│   ├── keyboards.py     #   دکمه‌ها و چیدمان پیش‌فرض
│   ├── design.py        #   ذخیره و رندر طراحی ادمین
│   └── fallback.py      #   جایگزینی خودکار ایموجی پرمیوم در صورت نیاز
├── handlers/            # start، download، admin، design (استودیو)، cookies
├── services/            # yt-dlp، gallery-dl، اسپاتیفای، ffmpeg، کوکی
├── sender.py            # ارسال فایل‌ها / آلبوم‌ها
└── progress.py          # پیام وضعیت، نوار پیشرفت و استیکر هر مرحله
install.sh               # نصب‌کننده خودکار
```

اجرای تست‌ها: `pip install -r requirements-dev.txt && BOT_TOKEN=x pytest`
